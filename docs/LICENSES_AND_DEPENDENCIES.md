# Licenses and dependencies

## Runtime dependencies (shipped to Foundry)
**None.** The module uses Foundry's global `PIXI` (PixiJS 7.x in Foundry v13) and Foundry's own APIs.
No third-party code is bundled.

## Spine format note
"Spine" is a trademark of Esoteric Software. A future export to the Spine JSON *format* (as Rigby2D
and SpriteForge do) is for interoperability only; we never use or ship the Spine Runtimes, whose
license requires a Spine Editor license.

## Assets
- Test sprites in `test/sprites/` are generated by `tools/gen_test_sprites.py` in this repository
  (original, procedural pixel art) — no third-party art.
- GMs' own sprites stay in their world folders and are never modified or uploaded anywhere else.

## Ecosystem modules
fu-animations vendors MIT code (Sprite Fusion VFX, pixelfx) and references a paid sound pack that
must not be redistributed. This module shares no files with it; integration is through
`game.modules.get('fu-animations').api` at runtime only.
